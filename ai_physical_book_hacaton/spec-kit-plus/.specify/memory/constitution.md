# Physical AI & Humanoid Robotics Textbook Constitution

## Core Principles

### I. Textbook Completeness
Produce a complete multi-chapter textbook following the given chapter outline.

### II. Content Accuracy & Depth
Ensure all content is accurate, actionable, industry-standard, and deeply technical. All explanations must start from fundamentals and progress to expert-level mastery.

### III. Platform Compatibility
Make the book compatible with Docusaurus + Context7 MCP + RAG chatbot integration.

### IV. Chapter Content Structure
All chapters contain: Concepts, Diagrams (ASCII or Mermaid), Python/ROS2 code, Simulation steps, Isaac workflows, Real vs Sim discussions, Labs and quizzes.

### V. Localization & Personalization
Add personalization and Urdu translation hooks.

### VI. GitHub Readiness
Deliver perfect GitHub-ready output.

### VII. Pedagogical Approach
Use simple, clear, authoritative tone. Every chapter ends with Practical Labs + Exercises.

### VIII. Spec-Kit Adherence
Follow all Spec-Kit patterns (constitution → spec → plan → tasks → red/green/refactor → explainer → phr).

## Governance

Constitution supersedes all other practices. Amendments require documentation, approval, and a migration plan. All PRs/reviews must verify compliance. Complexity must be justified. Use CLAUDE.md for runtime development guidance.
